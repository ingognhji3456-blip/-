# 한 장 더

한가운데 덱을 눌러 카드를 뽑고, 별을 모아 레벨을 올리는 픽셀 카드 뽑기 게임이에요.
`index.html` 하나로 돌아가요. 브라우저로 열면 바로 시작해요.

지금은 카드 뽑기와 별 레벨만 남겨 둔 기본판이에요. 코인, 업그레이드, 팩, 부적, 환생 같은 기능은 모두 뺐어요(이전 커밋에 남아 있어요).

## 하는 법

- **뽑기**: 가운데 덱을 누르면 카드 한 장이 뒤집히며 튀어나가요. 키보드에서는 스페이스나 엔터로 눌러요.
  - 카드는 일반 52장(♠ ♥ ♦ ♣ × A~K) 가운데 무작위로 나와요.
- **쿨타임**: 한 장 뽑으면 5초 동안은 다시 뽑을 수 없어요.
  - 덱 오른쪽 위 동그라미에서 금색이 한 바퀴 돌며 남은 초를 보여 주고, 덱 둘레 고리도 같이 차올라요. 기다리는 동안 덱은 어둡게 보여요.
  - 쿨타임 중에 누르면 덱이 살짝 흔들리고 막힌 소리가 나요. 다 돌면 덱이 다시 밝아지며 띵 소리가 나요.
- **별 레벨**: 카드 한 장마다 별 1개가 맨 아래 막대에 모여요. 막대가 차면 레벨이 올라요.
  - 레벨 1은 별 30개, 그 뒤로 레벨마다 필요한 별이 12%씩 늘어요.
  - 레벨이 오르면 알림이 뜨고, 소리와 불꽃이 나요.
- **레벨 보상 · 능력 카드**: 레벨이 오르면 능력 카드 3장을 받아요. 뒤집기 전 카드를 눌러 한 장씩 열거나 **모두 뒤집기**를 눌러요.
  - 장마다 능력 하나와 등급 하나가 무작위로 정해져요. 등급이 높을수록 능력이 세요.
  - 받은 능력은 바로 적용되고, 같은 능력은 겹쳐 쌓여요. 지금 가진 능력은 별 막대 바로 위에 짧게 보여요.
  - 보상 창을 열기 전에 게임을 닫아도 받을 카드는 남아 있다가 다음에 열려요.

| 등급 | 확률 |
| --- | --- |
| 일반 | 55% |
| 희귀 | 28% |
| 영웅 | 12% |
| 전설 | 4% |
| 신화 | 1% |

| 능력 | 일반 → 희귀 → 영웅 → 전설 → 신화 |
| --- | --- |
| ⏱️ 빠른 손 | 쿨타임 −3% · −6% · −10% · −18% · −30% (곱해서 쌓이고, 0.5초보다 짧아지지 않아요) |
| ⭐ 별 주머니 | 뽑을 때마다 별 +1 · +2 · +3 · +5 · +8 |
| 💫 별빛 | 모든 별 +10% · +20% · +35% · +60% · +100% |
| 🃏 두 장 뽑기 | 5% · 10% · 15% · 25% · 40% 확률로 한 장 더 (100%를 넘으면 한 장은 꼭 더 나와요) |
| 🍀 행운 별 | 3% · 6% · 10% · 15% · 25% 확률로 그 카드 별 ×5 (최대 100%) |
| ⚡ 번개 손 | 4% · 8% · 12% · 20% · 30% 확률로 쿨타임 없이 바로 또 뽑아요 (최대 80%) |
| 🐾 고양이 손 | 30초 · 20초 · 12초 · 8초 · 5초마다 저절로 한 장 (여러 장이면 더 자주) |

- 처음 시작하면 덱 아래에 "눌러서 카드 뽑기!" 말풍선이 떠요. 쿨타임 동안은 숨고, 세 장을 뽑으면 더 나오지 않아요.

## 저장

이 브라우저의 `localStorage`(`han-jang-deo-v1`)에 별 레벨, 모은 별, 뽑은 장수, 받은 능력 카드, 아직 안 연 레벨 보상을 5초마다, 그리고 창을 닫거나 숨길 때 저장해요.
예전 판에서 쌓은 별 레벨과 뽑은 장수는 그대로 가져와요.

## 파일 구성

- `index.html` 안에 스타일, `core-rules` 스크립트(무늬 · 숫자 · 레벨 공식 · 쿨타임 `DRAW_COOLDOWN` · 등급 `GRADES` · 능력 `ABILITIES`), 화면 스크립트가 차례로 들어 있어요.
- 카드, 덱 뒷면, 능력 카드 틀, 별 아이콘은 캔버스에 픽셀로 그려요. 능력 그림은 그 위에 이모지로 얹어요. 글꼴은 Google Fonts의 Pixelify Sans(숫자)와 Jua(한글)를 써요.
