# 동심원 도시

시청 하나에서 시작해 동심원을 따라 한 겹씩 넓혀 가는 도시 클릭 게임이에요.
`index.html` 하나로 돌아가요. 브라우저로 열면 바로 시작해요.

## 세 가지 축

| 요소 | 하는 일 |
| --- | --- |
| **클릭** | 시청을 눌러 세금을 걷어요. 도면 한가운데의 시청 칸을 눌러도 돼요. |
| **돈** | 땅에 건물을 지으면 초마다 세금이 들어와요. 주택부터 랜드마크 타워까지 8종이에요. 지은 건물은 10단계까지 키울 수 있어요. |
| **확장** | 원형 도면은 시청을 둘러싼 5겹의 고리로 되어 있어요. 개발을 승인할 때마다 바깥 고리의 땅이 열리고, 도시 이름이 동심리 → 동심읍 → 동심시 → 동심광역시 → 동심특별시로 올라가요. |

## 중심에 가까울수록 비싸다

| 고리 | 개발 비용 | 수입 배율 |
| --- | --- | --- |
| 도심 | 처음부터 | ×2 |
| 부도심 | 1만 원 | ×1.6 |
| 생활권 | 60만 원 | ×1.3 |
| 신도시 | 2,500만 원 | ×1.15 |
| 광역권 | 30억 원 | ×1 |

같은 건물도 시청 가까이에 있으면 더 많이 벌어요. 그래서 도심의 낡은 주택을 허물고 고층 빌딩을 올리는 **재개발**이 중요해요.
건물 짓기 목록에서 누르면 시청에서 가장 가까운 빈 땅에 짓고, 빈 땅이 없으면 수입이 가장 크게 느는 자리를 골라 재개발해요. 허물거나 재개발하면 원래 건물에 들인 돈의 절반을 돌려받아요.

## 건물

| 건물 | 용도 | 여는 고리 |
| --- | --- | --- |
| 주택 | 주거 | 도심 |
| 상점 | 상업 | 도심 |
| 공장 | 공업 | 부도심 |
| 사무실 | 업무 | 생활권 |
| 쇼핑몰 | 상업 | 생활권 |
| 고층 빌딩 | 업무 | 신도시 |
| 경기장 | 체육 | 광역권 |
| 랜드마크 타워 | 특별 | 광역권 |

도면 색은 도시계획 용도지역 색을 따랐어요. 주거는 노랑, 상업은 분홍, 공업은 보라, 업무는 파랑이에요.

## 그 밖에

- **정책**: 클릭 수입, 건물별 수입, 전체 수입을 올리는 정책을 시행해요. 교통(버스·지하철·공항), 홍보, 관광 정책이 있어요.
- **관광버스**: 가끔 화면에 나타나는 관광버스를 누르면 한 번에 큰돈을 벌거나, 건물 수입 ×5 또는 클릭 수입 ×10 효과를 받아요.
- **새 도시 계획**: 누적 수입이 1,000억 원을 넘으면 도시를 넘기고 시청 하나부터 다시 시작할 수 있어요. 노하우 하나마다 모든 수입이 영구히 5% 늘어요.
- **저장**: 진행 상황은 브라우저(localStorage)에 자동 저장돼요. 창을 닫아 둔 동안에도 최대 8시간까지 수입의 절반을 벌어요.

## 진행 속도 (시뮬레이션 기준)

초당 3번 클릭하며 효율 좋은 것부터 사는 경우, 부도심은 약 2분, 생활권은 약 6분, 신도시는 약 30분, 광역권은 약 1시간 뒤에 열려요. 그 뒤로 도시 전체를 경기장과 랜드마크 타워로 채우는 데 몇 시간이 걸려요.
