# 한 장 더

한가운데 덱을 눌러 카드를 뽑고, 별을 모아 레벨을 올리는 픽셀 카드 뽑기 게임이에요.
`index.html` 하나로 돌아가요. 브라우저로 열면 바로 시작해요.

지금은 카드 뽑기와 별 레벨만 남겨 둔 기본판이에요. 코인, 업그레이드, 팩, 부적, 환생 같은 기능은 모두 뺐어요(이전 커밋에 남아 있어요).

## 하는 법

- **뽑기**: 가운데 덱을 누르면 카드 한 장이 뒤집히며 튀어나가요. 키보드에서는 스페이스나 엔터로 눌러요.
  - 카드는 일반 52장(♠ ♥ ♦ ♣ × A~K) 가운데 무작위로 나와요.
- **별 레벨**: 카드 한 장마다 별 1개가 맨 아래 막대에 모여요. 막대가 차면 레벨이 올라요.
  - 레벨 1은 별 30개, 그 뒤로 레벨마다 필요한 별이 12%씩 늘어요.
  - 레벨이 오르면 알림이 뜨고, 소리와 불꽃이 나요.
- 처음 시작하면 덱 아래에 "눌러서 카드 뽑기!" 말풍선이 떠요. 세 장을 뽑으면 사라져요.

## 저장

이 브라우저의 `localStorage`(`han-jang-deo-v1`)에 별 레벨, 모은 별, 뽑은 장수를 5초마다, 그리고 창을 닫거나 숨길 때 저장해요.
예전 판에서 쌓은 별 레벨과 뽑은 장수는 그대로 가져와요.

## 파일 구성

- `index.html` 안에 스타일, `core-rules` 스크립트(무늬 · 숫자 · 레벨 공식), 화면 스크립트가 차례로 들어 있어요.
- 카드, 덱 뒷면, 별 아이콘은 캔버스에 픽셀로 그려요. 글꼴은 Google Fonts의 Pixelify Sans(숫자)와 Jua(한글)를 써요.
