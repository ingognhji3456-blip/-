# 여의도 개미

1,000만원으로 시작해 뉴스를 읽고 가상 종목 10개를 사고팔아 **10억**을 만드는 주식 게임이에요.
`index.html` 하나로 돌아가요. 브라우저로 열면 바로 시작해요.

## 하는 법

- 장은 **09:00에 열려 15:30에 닫혀요.** 5분마다 시세가 한 번 움직이고, 1배속이면 하루가 50초쯤이에요. 오른쪽 위 단추로 멈추거나 2배·4배로 빠르게 할 수 있어요.
- 시세표에서 종목을 고르고, 가운데 주문 칸에서 **매수**(빨강) 또는 **매도**(파랑)를 골라 수량을 정해요. 10% · 25% · 50% · 최대 단추를 누르면 가진 현금(팔 때는 가진 주식)에 맞춰 수량을 채워 줘요.
- 장이 열려 있을 때만 사고팔 수 있어요. 장이 닫히면 그날 결과(내 손익, 개미지수, 많이 오르고 내린 종목)와 **내일 장 시작 전 소식**이 나와요.
- **빨간색은 오름, 파란색은 내림**이에요. 한국 증시처럼요.
- 단축키: <kbd>Space</kbd> 멈춤·계속, <kbd>B</kbd> 매수, <kbd>S</kbd> 매도, 마감 화면에서 <kbd>Enter</kbd> 다음 날.

## 뉴스가 주가를 움직여요

장중에 하루 서너 번, 장 시작 전에 0–2번 뉴스가 나와요. 뉴스가 뜨는 순간 일부가 바로 반영되고, 나머지는 몇십 분에 걸쳐 따라와요. 뉴스 칸의 종목 이름을 누르면 그 종목 차트로 가요.

| 꼬리표 | 뜻 |
| --- | --- |
| 속보 | 한 종목의 좋은·나쁜 소식. 작은 소식(2–5%)부터 큰 소식(12–22%)까지. 바이오와 로켓AI는 더 크게 움직여요 |
| 테마 | 여러 종목이 함께 움직여요(AI · 전기차 · 한류 · 수출 · 배당) |
| 시장 | 모든 종목이 함께 움직여요 |
| 지라시 | 소문이에요. **반은 사실, 반은 거짓.** 나중에 공시(사실)나 해명(거짓)이 나오면 다시 크게 움직여요 |
| 시황 | 좋은 소식에 너무 오르면 차익 실현으로 밀리고, 나쁜 소식 뒤에는 반등하기도 해요 |

큰 소식과 시장 소식, 공시는 화면 아래 알림으로도 떠요. 시장에는 며칠씩 이어지는 강세장·약세장 흐름도 숨어 있어요.

## 진짜 증시를 닮은 규칙

- **상한가·하한가**: 한 종목은 하루에 전날 종가보다 30%까지만 오르고 내려요. 큰 뉴스가 한도에 막히면 다음 날 이어서 움직이기도 해요.
- **호가 단위**: 가격대에 따라 1원 · 5원 · 10원 · 50원 · 100원 · 500원 · 1,000원 단위로만 움직여요.
- **수수료와 세금**: 살 때와 팔 때 수수료 0.015%, 팔 때 세금 0.2%.
- **배당**: 10일마다 고소한식품과 든든은행을 가진 만큼 배당금이 들어와요.

## 화면

- **시세**: 종목마다 현재가, 전일 대비, 오늘 흐름 미니 차트. 가진 종목에는 ‘보유’, 상한가·하한가에 닿으면 표시가 붙어요.
- **차트·주문**: 오늘(5분) 차트에는 전일 종가 점선과 내 평균 단가 선이, 일봉 차트에는 5일선·20일선과 거래량이 보여요. 아래에 시가·고가·저가·상한가·하한가·거래량, 종토방 한마디, 주문 칸이 있어요.
- **내 계좌**: 총자산, 수익률, 오늘 손익, 실현 손익, 날마다 총자산 그래프, 가진 주식, 기록(이긴 매도 비율, 최고 한 방, 받은 배당), 최근 거래.
- **뉴스**: 시간순 뉴스 목록.
- 넓은 화면에서는 네 칸이 한 번에 보이고, 태블릿에서는 시세표 옆에 나머지가 탭으로, 폰에서는 아래 탭으로 한 칸씩 봐요.
- 밝은 화면과 어두운 화면을 모두 지원해요.

## 칭호

총자산에 따라 칭호가 올라요: 새내기 개미 → 개미(1,500만) → 성실한 개미(3,000만) → 슈퍼개미(5,000만) → 큰손(1억) → 여의도 고수(3억) → **전설의 개미(10억)**.
10억을 넘기면 축하 화면이 나오고 계속 키울 수 있어요. 자산이 100만원 아래로 떨어지면 깡통 계좌 안내가 나와요.

진행 상황은 브라우저(localStorage)에 저장돼요. 내 계좌 맨 아래 **새 게임**을 두 번 누르면 처음부터 다시 시작해요.
