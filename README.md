# 붕어빵 제국

골목 노점에서 붕어빵을 굽기 시작해 상권을 넓히고, 전국 체인을 넘어 우주 정거장 지점까지 키우는 클릭 게임입니다.
`index.html` 하나로 돌아가요. 브라우저로 열면 바로 시작합니다.

## 세 가지 축

| 요소 | 하는 일 |
| --- | --- |
| **클릭** | 철판 위 붕어빵을 눌러 한 마리씩 구워 팔아요. 빠르게 누르면 **화력**이 올라 클릭 수입이 최대 ×2(숯불 화로 구매 시 ×3)까지 늘어요. |
| **돈** | 붕어빵 틀, 알바생, 푸드트럭, 매장, 센트럴 키친 등 10단계 설비를 사면 자동 수입이 생겨요. 같은 설비를 살수록 값이 15%씩 올라요. 업그레이드로 클릭·설비·전체 수입을 키울 수 있어요. |
| **확장** | 9×9 상권 지도에서 내 땅과 맞닿은 칸을 사서 넓혀요. 한 칸마다 모든 수입 +2%, 칸 종류에 따라 추가 보너스가 붙어요. 상권이 넓어져야 다음 단계 설비가 열려요. |

### 상권 칸 종류

- **주** 주택가: 자동 수입 +3%
- **상** 상가: 모든 수입 +5%
- **학** 학교 앞: 클릭 수입 +25%
- **역** 역세권: 모든 수입 +12%, 땅값 1.5배
- **공** 공원: 황금 붕어빵이 8% 더 자주 나와요
- **강** 한강변: 모든 수입 +8%, 땅값 2배

### 그 밖에

- **황금 붕어빵**: 가끔 화면에 떠오르는 황금 붕어빵을 누르면 한 번에 큰돈을 벌거나, 자동 수입 ×5 또는 클릭 수입 ×10 효과를 받아요.
- **가게 물려주기**: 누적 수입이 1,000억 원을 넘으면 비법 레시피를 남기고 새 동네에서 처음부터 다시 시작할 수 있어요. 레시피 하나마다 모든 수입이 영구히 4% 늘어요.
- **저장**: 진행 상황은 브라우저(localStorage)에 자동 저장돼요. 창을 닫아 둔 동안에도 최대 8시간까지 자동 수입의 절반을 벌어요.

| 25칸 | 약 30분 | 냉동 붕어빵 공장 |

| 49칸 | 약 2시간 10분 | 붕어빵 테마파크 |
