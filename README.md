# 붕어빵 제국

리어카 한 대로 시작하는 붕어빵 장사 게임이에요. 손님이 주문한 붕어빵을 직접 구워서 건네고, 번 돈으로 틀과 메뉴를 늘려 가게를 본점까지 키워요.
`index.html` 하나로 돌아가요. 브라우저로 열면 바로 시작해요.

## 굽는 순서

1. **빈 틀**을 눌러 반죽을 부어요.
2. 한 번 더 눌러 고른 **속**을 넣어요. 속재료 칸이나 키보드 1~4로 고를 수 있어요.
3. 노릇해져 테두리가 빛나면 눌러서 **뒤집어요**. 3.5초 안에 안 뒤집으면 타요.
4. 다 익으면 눌러서 **진열대**로 옮겨요. 5초 안에 안 꺼내면 타요.
5. 주문한 붕어빵이 진열대에 다 있으면 **손님**을 눌러 건네요.

## 손님

| 손님 | 주문량 | 기다리는 시간 | 특징 |
| --- | --- | --- | --- |
| 꼬마 | 1~2개 | 길어요 | 슈크림을 좋아해요 |
| 학생 | 1~3개 | 보통 | 슈크림을 좋아해요 |
| 직장인 | 2~4개 | 짧아요 | 팁을 많이 줘요. 녹차를 좋아해요 |
| 할머니 | 3~6개 | 아주 길어요 | 피자 붕어빵을 좋아해요 |

빨리 건넬수록 팁을 더 받아요. 기다림 막대가 60% 넘게 남았으면 20%, 30% 넘게 남았으면 10%예요.
기다림 막대가 다 줄면 손님은 그냥 돌아가요.

## 하루 흐름

- 하루 장사는 100초예요. 마감 뒤에는 새 손님이 오지 않고, 기다리던 손님은 길어야 15초 더 기다려요.
- 문을 닫으면 판매 개수, 매출, 팁, 탄 붕어빵, 평점이 나오고, 번 돈으로 가게를 정비해요.
- 진행 상황은 하루가 끝날 때마다 브라우저(localStorage)에 저장돼요.

## 가게 확장

| 단계 | 비용 | 바뀌는 것 |
| --- | --- | --- |
| 리어카 노점 | 시작 | 손님 자리 2 · 틀 최대 3개 |
| 포장마차 | 3만 원 | 손님 자리 3 · 틀 최대 4개 · 값 ×1.25 · 슈크림, 알바생(꺼내기) |
| 골목 가게 | 10만 원 | 틀 최대 6개 · 값 ×1.6 · 녹차, 알바생(뒤집기) |
| 역 앞 매장 | 30만 원 | 손님 자리 4 · 틀 최대 8개 · 값 ×2.2 · 피자 붕어빵 |
| 붕어빵 제국 본점 | 100만 원 | 틀 최대 9개 · 값 ×3 |

## 장비와 메뉴

- **붕어빵 틀 추가**: 동시에 굽는 틀이 늘어요. 가게 단계마다 놓을 수 있는 최대 개수가 정해져 있어요.
- **화력 강화**: 한 면 굽는 시간이 4.0초에서 최대 2.2초까지 줄어요.
- **진열대 확장**: 보관 개수가 6개에서 최대 20개까지 늘어요.
- **친절 교육**: 손님이 기다려 주는 시간이 최대 1.6배로 늘어요.
- **전단지 홍보**: 손님이 더 자주 와요.
- **메뉴**: 슈크림(700원), 녹차(900원), 피자(1,200원). 가게 단계에 따라 값이 올라요.
- **알바생**: 꺼내기 담당은 다 익은 붕어빵을, 뒤집기 담당은 노릇해진 붕어빵을 알아서 처리해요.
