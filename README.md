# 중심별

한가운데 별 하나를 눌러 별빛을 모으고, 업그레이드 별을 하나씩 밝혀 별자리를 바깥으로 넓혀 가는 클릭 게임이에요.
`index.html` 하나로 돌아가요. 브라우저로 열면 바로 시작해요.

## 하는 법

- **클릭**: 한가운데 중심별을 눌러 별빛을 모아요.
- **밝히기**: 둘레의 별(업그레이드)을 눌러 별빛으로 밝혀요. 별 하나를 밝히면 그 바깥에 다음 별이 이어져 나타나요.
- **넓히기**: 별자리는 중심에서 여섯 갈래로 퍼져요. 바깥 고리로 갈수록 값이 비싸지고 효과도 커져요.
- PC에서는 별에 마우스를 올리면 정보가 나오고, 누르면 바로 밝혀요. 폰에서는 한 번 누르면 정보, 한 번 더 누르면 밝혀요.
- 끌어서 별자리를 움직이고, 휠이나 두 손가락으로 확대·축소해요. **가운데로**를 누르면 다시 전체가 보이게 맞춰요.

## 여섯 갈래

| 갈래 | 하는 일 |
| --- | --- |
| 손끝 | 클릭 한 번에 모으는 별빛, 연타 보너스 |
| 위성 | 가만히 있어도 들어오는 별빛(초당 수입) |
| 증폭 | 모든 별빛 배율, 별 밝히는 값 할인 |
| 행운 | 섬광(가끔 몇 배로 터지는 클릭) 확률과 배율 |
| 유성 | 가끔 지나가는 유성. 잡으면 별빛을 한꺼번에 주거나 30초쯤 모든 별빛 ×3 |
| 공명 | 밝힌 별 수만큼 늘어나는 보너스, 저절로 반짝이는 자동 클릭, 자리 비운 동안 모으기 |

밝힌 별 수에 따라 중심별이 자라요: 작은 별 → 별자리 → 성단 → 성운 → 은하 → 우주.
별은 모두 40개, 단계를 다 합치면 181단계예요.

## 진행 속도 (시뮬레이션 기준)

초당 4번 누르며 효율 좋은 별부터 밝히는 경우, 12개는 약 5분, 22개는 약 13분, 32개는 약 40분, 전부 끝까지 밝히는 데는 약 3시간이 걸려요.
초당 1번만 누르면 32개까지 약 1시간 15분이 걸려요.

진행 상황은 브라우저(localStorage)에 자동 저장돼요. 창을 닫아 둔 동안에도 최대 8시간까지 초당 수입의 절반을 모아요(공명 갈래에서 더 늘릴 수 있어요).
