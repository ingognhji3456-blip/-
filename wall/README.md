# 벽 부수기

맨주먹으로 눈앞의 벽을 때려 부수는 1인칭 2D 픽셀 게임이에요.
`index.html` 하나로 돌아가요. 브라우저로 열면 바로 시작해요.

## 하는 법

- **왼쪽 클릭**: 주먹을 뻗어 벽을 때려요. 누를 때마다 **왼손 → 오른손 → 왼손 …** 차례로 번갈아 나가요.
- 주먹은 마우스 조준점(십자 표시)이 있는 곳으로 날아가요. 금도 맞은 자리에 생겨요.
- 폰에서는 화면을 누른 곳을 때려요.
- **M** 키나 오른쪽 위 **소리** 단추로 소리를 끄고 켜요(설정은 기억돼요).

## 금이 가고 부서지는 순서

1. 처음 몇 대는 맞은 자리만 살짝 패이고, 아주 짧은 금이 생겨요.
2. 맞을수록 금이 길어지고 갈래가 늘고, 굵어져요. 예전에 때린 자리와 금이 이어져 벽 전체가 거미줄처럼 갈라져요.
3. 내구도가 0이 되면 벽이 조각조각 깨져요. 맞은 자리 근처 조각은 잘게 부서져 화면 쪽으로 튀어나오고, 나머지는 와르르 무너져요.
4. 부서진 벽 너머 통로 끝에 **다음 벽**이 보이고, 앞으로 걸어가 그 벽 앞에 서요.

## 벽 종류

| 순서 | 벽 | 내구도(주먹 수) | 특징 |
| --- | --- | --- | --- |
| 1 | 나무 판자벽 | 12 | 나뭇결을 따라 세로로 갈라져요 |
| 2 | 벽돌벽 | 18 | |
| 3 | 돌벽 | 24 | |
| 4 | 콘크리트벽 | 30 | |
| 5 | 강철벽 | 38 | 금이 곧게 뻗고, 때리면 쇳소리가 나요 |
| 6 | 흑요석벽 | 46 | 유리처럼 곧게 금이 가고, 금이 보랏빛으로 빛나요 |

여섯 번째 벽까지 부수면 다시 나무 판자벽부터 `+1`, `+2` … 로 강해져서 돌아와요(한 바퀴마다 내구도 +50%).

## 만든 방식

- 화면은 짧은 쪽이 180픽셀쯤 되는 작은 캔버스에 그리고, 정수배로 키워 픽셀이 또렷하게 보여요.
- 그림 파일은 하나도 없어요. 벽 무늬, 금, 팔과 주먹, 부서지는 조각을 모두 코드로 한 픽셀씩 그려요.
- 효과음도 Web Audio로 그 자리에서 합성해요.
- 글꼴은 [갈무리](https://github.com/quiple/galmuri)(SIL OFL)를 jsDelivr에서 불러와요. 못 불러오면 기본 글꼴로 보여요.
